MASSAGE POS V8 - NO EMAIL LOGIN

QR payment: Take Photo / Choose Photo -> Confirm -> uploads to Supabase automatically.
Owner Dashboard: QR transaction -> Print / View Slip.
No email/password prompt.

NOTE: This is a PILOT configuration for ONE shop. Slip images are stored in a public Supabase bucket with unguessable URLs. Anyone with an image URL can view it; the Owner PIN only gates the POS interface, not the underlying URL. Avoid uploading sensitive slips until a private server-backed version is ready.

Sales, jobs and transaction history remain local to the browser. Other devices will not show the same transactions yet. Only the slip images are stored in Supabase.

To deploy, replace index.html, app.js and style.css in your GitHub repo.
